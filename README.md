# Smart Spend Tracker

Smart Spend Tracker is a web application for tracking and analyzing personal expenses with automated AI categorization.

Possible spend inputs and processing include:

* text descriptions in natural language;
* audio messages and voice input;
* automatic breakdown of receipts into separate categories;
* custom category assignment and expense tagging.

The main idea is to allow users to quickly record daily expenses without manual sorting while the AI categorizes each item automatically.
