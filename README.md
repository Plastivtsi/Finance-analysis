# Smart Spend Tracker

Smart Spend Tracker is a web application for recording, analyzing, and visualizing personal expenses with automated AI classification and statistics.

Possible spend inputs and processing include:

* text descriptions of purchases in natural language;
* automatic parsing of transaction descriptions into itemized amounts;
* automated grouping of individual expenses into predefined categories using neural networks;
* generation of detailed spending statistics and visual analytics over time.

The main idea is to allow users to quickly record daily expenses without manual sorting, relying on AI models to organize items into relevant categories and build expenditure statistics automatically.
